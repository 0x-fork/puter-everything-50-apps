# Chess — app store listing

The listing lives at [`STORE_LISTING.md`](../STORE_LISTING.md) in the repository
root: name, tagline, short and long description, features, audience, keywords,
and category.

The promotional images a submission form asks for are in
`store/screenshots/<size>/`, four per size, and are regenerated with
`node tools/store-promo.mjs` (see the header of that file).
