The composite fitting fixtures exercise nested LIN and COMPOSITE layouts with independent canvases, height and font rules, physical dimension references, copied user variables, signed factors, and references crossing layout boundaries. They vary dimensions, text, font size, ancestor ownership, and sibling order.

The `diagram-composite-*-native.json` fixtures contain authored DiagramML data/layout definitions and expected drawing geometry and text properties measured after the native reference application laid out the control presentations. Glyph measurements were recorded separately with Chromium. A measurement key includes the text, box dimensions, fonts, and margins; an unrecorded trial fails instead of supplying an estimated measurement. Native drawing bounds use EMUs, with at most one EMU of tolerance for serialization rounding.

Reserved allocation, completed text drawing, and reference values have different lifetimes. A parent geometry retry can project a child's drawing without reopening its local canvas or replacing a retained equality allocation. The regression suites check those distinctions through both text geometry and other shapes or margins consuming the same references. Repeated reflow must leave the source definitions unchanged.

`diagram-composite-height-allocation-native.json` varies LIN/COMPOSITE parents, container height preferences, automatic/literal/parent-linked heights, offsets, dimensions, and custom Arial 15/21 pt text. Every layout was validated before native reference regeneration, and all 32 native PDF pages were visually inspected. Native geometry can match while content overflows: `expectedContentFit` records that distinction instead of implying that matching boxes fit their text. The passing unit cases assert geometry, fonts, content feasibility, repeatability and input immutability. The strict native audit includes all 32 controls, including unresolved ownership cases; a mismatch remains a failing audit result.

`diagram-composite-shared-height-retry.json` contains additional authored controls with real Chromium measurements, not native geometry goldens. Its tests assert that every member of an equal-height domain remains fitted after a physical canvas replacement, including reversed member order. An overridden numeric expression must not silently remove a member from the semantic equality group.
