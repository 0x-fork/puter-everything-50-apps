# Everything hero

The README uses [34-app-wall-intact.png](variants/34-app-wall-intact.png),
a direct composition of 18 unchanged captures from `screenshots/`.

Screenshots are scaled proportionally, with no retouching, filters, opacity,
or overlays. Only the outer canvas crops peripheral windows. 3D, Video Studio,
Audio Studio, and Chess are fully visible, and every column extends past both
frame edges. Meetings uses the earlier `keynote-slide-07-meetings.png` capture.

All source screenshots remain byte-for-byte unchanged. Visible hero panels were
verified pixel-for-pixel against their proportionally scaled source images.
